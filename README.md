## 💡 What is CivicHero AI?

CivicHero AI empowers citizens to **report, verify, track, and resolve** local infrastructure issues — potholes, water leaks, broken streetlights, garbage dumps — through AI automation and gamified participation.

---

## ✨ Features

- **6-Agent Gemini AI Pipeline** — Vision analysis, classification, duplicate detection, impact prediction, priority scoring, and resolution planning
- **Geo-Location Map** — Pin and visualize issues across wards
- **Community Verification** — Citizens validate reports on the ground
- **Real-Time Tracking** — `Reported → Verified → In Progress → Resolved`
- **AI Ward Health Scanner** — Infrastructure health scores for roads, water, lighting, cleanliness & safety
- **Smart AI Search** — Natural language issue search powered by Gemini
- **Gamification** — Points, badges, quests, and live leaderboard

## 🚀 Run Locally

```bash
git clone https://github.com/YOURUSERNAME/civichero-ai.git
cd civichero-ai
npm install

# Add GEMINI_API_KEY to .env.local
npm run dev
```

App runs at `http://localhost:3000`
